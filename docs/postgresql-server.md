# AXDB

AXDB is a binary-compatible, open source drop-in replacement for PostgreSQL {{pgversion}}. It functions identically to upstream PostgreSQL, allowing you to [migrate](migration.md) seamlessly between the two.

In addition to upstream functionality, AXDB includes enhancements that enable advanced extension capabilities.

For a broader overview of integrated tooling and deployment guidance, start with the [AXDB Quickstart guide](quick-start.md).
